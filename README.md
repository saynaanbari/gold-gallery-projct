## Description

Gold Gallery is a full-featured jewelry e-commerce application built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**. The project includes a customer-facing storefront and a dedicated admin panel, providing a complete online shopping experience.

Customers can browse jewelry products, explore categories, view product details, add items to the shopping cart, complete the checkout process, and place orders. Administrators can manage products, inventory, and customer orders through a dedicated dashboard.

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Redux Toolkit
- Axios
- React Hook Form
- Swiper
- React Hot Toast
- React Icons

## Features

### 🛍️ Storefront

- Browse jewelry products
- Browse products by category
- View detailed product information
- Add and remove items from the shopping cart
- Checkout page
- Payment page
- Place orders
- User authentication
- Responsive design
- Modern and clean user interface

### ⚙️ Admin Panel

- Admin authentication
- Dashboard overview
- Product management (Create, Read, Update, Delete)
- Inventory management
- Order management
- Responsive admin dashboard

## Highlights

- Built with Next.js App Router
- Component-based architecture
- State management with Redux Toolkit
- REST API integration using Axios
- Form handling with React Hook Form
- Interactive product sliders with Swiper
- Toast notifications with React Hot Toast
- Modern icon system with React Icons
- Strongly typed with TypeScript
- Responsive design
- Scalable and maintainable project structure
